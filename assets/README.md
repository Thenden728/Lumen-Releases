# Визуальные материалы Lumen

Обложка и карточки используют авторские работы, включённые в Lumen 0.1.0.
`black-iris.gif` — пятисекундный фрагмент реального `black-iris.mp4`, уменьшенный до 720 пикселей и 15 кадров/с для страницы GitHub; это не качество исходного видео.

`interface-home.png`, `interface-live.png` и `music-widget.png` сняты с текущих элементов интерфейса в изолированном демонстрационном профиле. Личные библиотеки, настройки и учётные данные не использованы.

`social-preview.png` — обложка 1280 × 640 для предпросмотра ссылки на репозиторий.

Условия использования: [TERMS.txt](../TERMS.txt).
