# Lumen

### Wallpaper Studio для Windows

Фото, живые обои и музыкальный виджет — в одном приложении с чёрным
интерфейсом и мягкими розовыми акцентами.

## Возможности

- Фото на рабочий стол и экран блокировки; живые обои на рабочий стол.
- Несколько каталогов, поиск, фильтры и выбор качества.
- Любимые с собственными папками, история и управление загрузками.
- Автоматическая смена по расписанию из каталогов или любимых.
- Музыкальный виджет с обложкой, управлением воспроизведением и громкостью приложения.
- Авторские динамические работы и настройки эффектов.

### Установка

1. Скачайте `Lumen-Setup-0.1.0-x64.exe` и запустите его.
2. Пройдите мастер установки. Приложение появится в меню «Пуск» под именем Lumen.
3. Выберите обои или откройте «Музыку», чтобы включить музыкальный виджет.

Python, Blender и отдельные команды не нужны. Установка выполняется для текущего
пользователя без прав администратора. Автоматическая смена и автозапуск включаются
по вашему выбору. Установщик пока не имеет цифровой подписи издателя.

### Обновление и удаление

Для обновления установите новую версию поверх прежней. Настройки и библиотека
сохраняются. Удалить приложение можно через «Установленные приложения» Windows;
личные настройки и скачанные файлы остаются на устройстве.

Архив `Lumen-Dependency-Sources-0.1.0.zip` содержит исходники сторонних библиотек
и инструкции сборки. Для установки Lumen он не нужен. Контрольные суммы файлов
приведены в `SHA256SUMS.txt` на странице версии.

Приложение разрабатывается для Windows 10/11 x64. Возможности источников,
воспроизведения и интеграций зависят от доступности сервисов и оборудования.
